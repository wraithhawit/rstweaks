RSTWEAKS / RSPERF - WHAT EACH VERSION DID
=========================================

One or two lines per version, newest first. This file is the short form; CHANGELOG.md is
the detailed history and carries the reasoning. BOTH ARE MAINTAINED - every version bump
gets an entry in each. CHANGELOG.md was backfilled to 0.2.80 on 2026-08-16; the only gap
left is 0.2.18 - 0.2.46, which was never written down anywhere and is recorded there as
one honest block rather than reconstructed.

The mod was called "rsperf" up to 0.2.40 and "rstweaks" from 0.2.41. Searching a log for
"rstweaks" will miss anyone still running an older build.


UNRELEASED (in source, not yet in a built jar)
----------------------------------------------
  sparkProfile task. `./gradlew sparkProfile --args="<spark link|code|file>"` decodes a
  spark profile from the command line and ranks frames by share of the thread. A spark
  link is a protobuf payload on bytebin, not a web page.


0.2.80  Crafting-grid container refill no longer needs patterns or fluid substitution; the
        only limit is whether the network can pay. Live for everyone - it had been dead
        since 0.2.79.

0.2.79  Fluid substitution PARKED - Ultramegaaa's "Refined Fluid Substitution" covers it.
        Ours stays, default off, no longer developed. Config text only.

0.2.78  BUG FIX - putting a stored fluid pattern back in the grid wiped the Processing tab.
        Also: separate client and server matrices, immediate tab rebind (no flash), tab
        state moved onto RS's synced property channel.

0.2.77  The Pattern Grid remembers which tab it was on, synced as an RS menu property. The
        client no longer announces "Processing" on every open, which was overwriting it.

0.2.76  Diagnostics removed; the fluid tab's own matrix confirmed in game.

0.2.75  BUG FIX - Clear wiped the Processing matrix while on the fluid tab, leaving no way
        out of a fluid tab stuck holding contents in its 159 off-screen slots.

0.2.74  BUG FIX - auto-fill did nothing on the fluid tab: 0.2.72's container did not carry
        the marker interface the input-slot lookup tests for, so it found no inputs.

0.2.73  BUG FIX - auto-fill wrote to the Processing container while the slots were bound to
        the fluid one. Output-slot lookup no longer breaks after a rebind either.

0.2.72  BUG FIX - 0.2.71 would not launch. Never ship a class in another mod's package:
        NeoForge loads mods as named modules, so it fails at module resolution.

0.2.71  DID NOT LAUNCH. The fluid tab gets its own matrix and a tab switch rebinds slots
        instead of copying NBT. The old stash is gone with no migration.

0.2.70  Diagnostics removed; the mark confirmed working in game.

0.2.69  BUG FIX - the 0.2.65 mark had never once been written. Cable Tiers cancels the same
        method at RETURN, so our callback was never reached. Ours is now priority 500.

0.2.68  Diagnostic build, no behaviour change.

0.2.67  BUG FIX - the mark still was not written: it read the block entity's stash flag
        rather than the menu's tab, which is the only thing that knows.

0.2.66  The mark is required - convertUnmarkedFluidPatterns defaults off. Patterns encoded
        before 0.2.65 revert to Processing and need re-encoding. (0.2.65 never launched.)

0.2.65  Fluid patterns carry a rstweaks:fluid_substitution component and the resolver reads
        it, instead of guessing from contents and mistaking real machine recipes for swaps.
        Config: convertUnmarkedFluidPatterns.

0.2.64  BUG FIX - autocrafting tasks ate their ingredients and reported success, in every
        build from 0.2.57. A null @Unique field threw, and RS treats any throw in a task
        step as completion: toast fired, internal storage dropped. LavaSurf's item loss.

0.2.63  skipEmptyCompositeExtract defaults OFF. The network's resource list can be wrong
        rather than merely late, and 0.2.62 made extraction trust it.

0.2.62  Empty-extract skip - CompositeStorage.extract returns 0 without walking any storage
        when the network list says it holds none. Config: skipEmptyCompositeExtract.

0.2.61  Removed the crafting-grid diagnostic logging from 0.2.60. No behaviour change.

0.2.60  Temporary logging around the crafting-grid refill. The reported problem turned
        out not to be a bug.

0.2.59  Crafting-grid refill now spends a full container from storage before spending
        fluid. Stock before tank.

0.2.58  Crafting grid refills containers. Craft a cake and the milk buckets stay milk
        buckets; the network pays the milk. RS already did this for ordinary
        ingredients, never for ones handed back as containers.
        Config: refillContainersInCraftingGrid (default on; needed fluid substitution
        until 0.2.80).

0.2.57  BUG FIX - durability duplication. A recipe burning two different durable tools
        recorded only one, so the other's byproduct came back exactly as encoded: a
        repaired tool, out of nothing. Now tracked per tool.

0.2.56  BUG FIX - item loss in the external slot index, present in every build since
        0.2.3. When an extraction pulled from one candidate slot and then met a stale
        one, the items already taken were never reported to Refined Storage - removed
        from the chest and destroyed. One missing line.

0.2.55  Removed the dead two-way arrow code and wrote down why it fails: a mirrored
        blit via scale(-1,1,1) renders nothing, near-certainly culled winding.

0.2.54  Attempted a two-way arrow on the fluid pattern tooltip. Did not render.

0.2.53  Fluid pattern tooltip shows the container, an arrow and the fluid, instead of
        RS's matrix row of mostly-blank cells.

0.2.52  Defaults changed: lpPlanner and durabilityAwarePlanning now default ON;
        fluidSubstitutionPatterns stays off pending more testing. Config text for both
        rewritten - the old warnings described bugs that had since been fixed.

0.2.51  Refined Storage's Processing tab no longer stays lit while the fluid
        substitution tab is selected.

0.2.50  The two tabs keep separate patterns. The inactive tab's matrix is stashed as NBT
        on the Pattern Grid block entity and swapped in on a tab change, so it survives
        closing the grid and a world reload. No new containers, nothing new to sync.

0.2.49  Diagnostics for the tab signal, which proved the channel was working.

0.2.48  Pattern item renamed "Fluid Substitution Pattern". Auto-fill no longer fires in
        RS's own Processing tab: the client now tells the server which tab is open, over
        a vanilla menu-button click.

0.2.47  Shortfall reporting. An impossible craft now says what you are short of -
        "lava_bucket available 4, missing 6" instead of "missing 10000mB lava" - by
        re-solving with outside supply allowed and reading the difference.


0.2.18 - 0.2.46  FLUID SUBSTITUTION (not individually recorded)
---------------------------------------------------------------
        The changelog lapsed across this range. What was built, in rough order:

        - Fluid substitution patterns: a pattern that only empties or fills a container
          is settled by RS itself instead of waiting for a machine that does not exist.
        - The Pattern Grid tab and its 1-to-2 layout, drawn over the processing matrix.
        - Auto-fill: put a bucket or a fluid in, get the other side filled in for you.
        - Reversible patterns - one encoded pattern registers its mirror, so emptying
          and filling both work from one.
        - Empty containers no longer advertised as craftable (moved to byproducts).
        - 0.2.30-31: auto-fill direction fixes.
        - 0.2.40: last build under the name "rsperf".
        - 0.2.41: renamed to "rstweaks".
        - 0.2.45: swallowed RS's PatternCycleDetectedException to let it build a
          preview. Reverted in 0.2.46 - it left Start enabled on an impossible craft.
        - 0.2.46: that revert.


0.2.17  Split the mixin configs so an absent optional mod (Step Crafter, Cable Tiers,
        Functional Storage) no longer takes every other optimization down with it. The
        startup and chat lines now list what is actually running.

0.2.16  Durability-aware planning. A tool that wears out is treated as a supply of uses,
        so one infusion crystal covers as many crafts as it has durability. Three parts:
        planner, storage scan, and an executor that ages what the pattern hands back.

0.2.15  The chat summary was suppressing itself - it decided whether to report from four
        counters while the body reported nine. All counters are deltas now.
        Added /rstweaks stats.

0.2.14  External storage stopped probing providers that cannot hold the resource type at
        all - an energy request no longer asks every item inventory in the network.
        Config: skipMismatchedStorageTypes.

0.2.13  The preview no longer doubles a self-duplicating craft (192 templates announced
        as 384).

0.2.12  Self-duplicating recipes work. Netherite templates consume what they produce, so
        the root pattern's outputs are now held in the task when it also consumes them.
        recycleRootByproducts renamed keepRecycledResourcesInTask.

0.2.11  The preview no longer claims to craft recycled containers. One bucket going round
        128 times is one bucket.

0.2.10  Fixed 0.2.9, which could not craft at all: Mixin does not search the hierarchy
        for shadowed fields, and the shadowed field was on the superclass.

0.2.9   Found why RS demands 64 buckets for 64 rice slimeballs - the executor, not the
        planner. Root byproducts now stay in the task.
        Config: recycleRootByproducts.

0.2.8   Fixed LP-planned crafts sitting forever. A cycle needs working capital: net
        consumption of zero and required capital of zero are different claims.
        Added the executability self-test and the headless runner.

0.2.7   An accepted LP plan logs the whole plan, not just its size.

0.2.6   RS's autocrafting DEBUG logging was 71.8% of the server thread - 209 MB of
        debug.log in 29 seconds. Raised that logger to INFO.
        Config: silenceAutocraftingDebugLog. Worth reporting upstream on its own.

0.2.5   The config file is readable: blank lines between entries.

0.2.4   lpPlanner defaulted to OFF after it broke crafting on a live server.

0.2.3   Slot index for external inventory extraction - 42.9 ms/tick, the single largest
        cost on a struggling server. The index only suggests slots; every one is re-read
        live. Config: externalStorageSlotIndex, externalIndexTtlTicks, minSlotsToIndex.

0.2.2   getSlots() no longer called once per slot while scanning external inventories.
        A 5,000-slot controller made 5,001 calls. ~6 ms/tick.

0.2.1   Drawer Controller connectivity check made O(1). Was 13.97% of the server thread,
        the largest single frame.

0.2.0   Version made visible at runtime. LP planner decline reasons split by cause, and
        infeasible plans name the blocking resource.

0.1.0   Everything up to and including the linear planner, shipped as one version across
        roughly eight builds - which is what prompted versioning at all.
        Measured: 5.29 -> 19.98 TPS.
